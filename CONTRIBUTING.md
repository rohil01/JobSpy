# Contributing

`jobsniffer` is a personal, AI-assisted fork of [speedyapply/JobSpy](https://github.com/speedyapply/JobSpy).

**This project does not send pull requests upstream, and will not accept pull requests intended for
forwarding upstream** — out of respect for maintainers who haven't opted into AI-authored
contributions. If you want to contribute to the original project, go to
[speedyapply/JobSpy](https://github.com/speedyapply/JobSpy) and work there directly.

Issues and pull requests against *this* fork are welcome for changes that only make sense here. See
the README for current scraper verification status. Nothing filed here is ever forwarded upstream.
